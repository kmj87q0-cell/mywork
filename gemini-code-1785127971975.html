비버 물류센터의 마법 바코드 복구하기

비버 물류센터에서는 스마트 화물 로봇이 택배 상자를 정확히 식별할 수 있도록 4×4 크기의 격자 모양 '마법 바코드'를 사용합니다. 배달 도중 상자가 긁혀 딱 1개의 칸 색상이 반대로 바뀌는 오류가 발생했습니다.

💡 마법 바코드 생성 규칙 (짝수 패리티)
• 가로 규칙: 각 행(가로줄)에 있는 검은색(■) 칸의 개수는 항상 짝수(0, 2, 4개)여야 합니다.
• 세로 규칙: 각 열(세로줄)에 있는 검은색(■) 칸의 개수 역시 항상 짝수(0, 2, 4개)여야 합니다.

아래 바코드를 보고 규칙에 어긋난 오류 칸을 직접 클릭하여 올바른 마법 바코드로 복구해보세요!

👆 오류가 발생한 칸을 찾아 클릭해보세요!

🔍 힌트: 한 줄씩 검은색 칸을 세어보세요!

각 행(가로)과 열(세로)의 검은색(■) 개수를 홀수인지 짝수인지 확인해보세요.

  • 1행: 검은색 2개 (짝수 ✔️)
  • 2행: 검은색 3개 (홀수 ❌ -> 오류가 있는 줄!)
  • 3행: 검은색 2개 (짝수 ✔️)
  • 4행: 검은색 2개 (짝수 ✔️)

가로줄(2행)을 찾았으니, 이제 몇 번째 열(세로줄)의 검은색 개수가 홀수인지 찾아 교차하는 칸을 클릭하세요!

🎉 정답: ② (2행, 3열)

오류가 발생한 칸은 2행 3열입니다. 해당 칸(검은색)을 흰색으로 바꾸면 모든 행과 열의 검은색 개수가 짝수가 됩니다.

💡 정보과학 원리: 패리티 비트(Parity Bit)

컴퓨터는 데이터를 전송하거나 저장할 때 오류가 발생했는지 확인하기 위해 '패리티 비트'라는 오류 검출 코드를 사용합니다. 문제처럼 가로와 세로 양방향으로 짝수 규칙(2차원 패리티 비트)을 적용하면, 데이터에 오류가 발생했을 때 어느 위치가 잘못되었는지 정확히 찾아내어 스스로 수정(오류 복구)까지 할 수 있습니다.
